# Desafios — Target

Soluções dos desafios de programação desenvolvidos em JavaScript.

## Requisitos

* [Node.js](https://nodejs.org/) instalado
* Git (opcional, caso o projeto seja clonado)

Para verificar se o Node.js está instalado:

```bash
node --version
```

## Como executar

Clone o repositório:

```bash
git clone https://github.com/szl0mo/target.git
```

Entre na pasta do projeto:

```bash
cd target
```

Os desafios podem ser executados individualmente utilizando o Node.js:

### Desafio 1

```bash
node desafio1.js
```

### Desafio 2

```bash
node desafio2.js
```

### Desafio 3

```bash
node desafio3.js
```

Não é necessário instalar dependências adicionais para executar os desafios.

## Tecnologias

* JavaScript
* Node.js
* JSON

## Observações

Os arquivos `desafio1.js`, `desafio2.js` e `desafio3.js` são executados separadamente. Caso algum desafio utilize arquivos auxiliares ou dados externos, eles devem permanecer nos caminhos indicados na estrutura do projeto.
